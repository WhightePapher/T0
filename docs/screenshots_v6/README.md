## 1. 逐条改动与实测

量法（`tool/measure_contrast.py`，与审图同法）：区块内取出现最多的颜色当底色，
取「与底色亮度差最大且像素数 ≥12」的颜色当字色，按 WCAG 相对亮度算比值。
同一脚本量 v4 旧图能得到审图里的原值（2.61 / 3.12 / 3.58 / 3.42 / 4.19 / 3.42），说明尺子没换。

### #2（P2）08 过渡帧文字切换点 —— 已修

整帧最小（同一脚本、同一批区块，v4 旧图 → v6 新图）：

| 帧 | 文件 | 改前最小 | 改后最小 |
|---|---|---|---|
| 实测 110ms | `10_transition_105ms.png` | 4.60（步骤条） | **9.07** |
| 实测 121ms | `07_transition_120ms.png` | 4.46（步骤条） | **8.27** |
| 实测 215ms | `08_transition_210ms.png` | **2.43（步骤条）/ 3.42（副标题）/ 3.58（主标题）** | **6.97（页面）/ 5.90（卡片）/ 6.97（步骤条）** |
| 实测 298ms | `09_transition_300ms.png` | 5.29（步骤条） | **7.63** |
| 实测 313ms | `11_transition_315ms.png` | 4.54（步骤条） | **6.64** |

改在三处常量（`lib/theme/palette.dart` 的 `T0Palette.lerp`）：

1. `foregroundSwitch` **0.5 → 0.35**（≈186ms，文字整块换边，仍是一个常量、一套动画）；
2. `surfaceGamma` **0.65 → 0.42**：底色更早落到深侧，210ms 这一帧已经是浅字压深底；
3. 兜底从「往同侧 ink 收 95%」改成「收到**亮度极值**」（白天侧纯黑、黑夜侧纯白，
   `guardFor(st)` 按面进度而不是时间生效）——中灰底上主题色最多 3.4~4.2，
   只有黑白能到 4.58（硬切的理论上限），这是 210ms 那一帧从 3.4 提到 6.9 的关键。

**整段过渡的最低点**：按同一套公式扫 4001 个 t，最低 **4.23**（审图那一版最低 2.43，
210ms 一带约 50ms 落在 3.4 附近）；低于 4.5 的区间只有 **182–191ms 这 9ms**（切换瞬间），
五个采样帧全部 ≥5.90。单元测试 `过渡全程：任一时刻文字/底的对比度都不低于 3:1` 仍全绿。

已知取舍：过渡中段强调色会被收到黑白（08 里 CTA 变白底黑字），落定后恢复品牌色 —— 这是
「中灰底 + 任意色相 = <4.5」的必然结果，v4 里同样存在（当时是收成近墨色）。
