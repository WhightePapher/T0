# screenshots_v8 · r3 顶栏（去假头像 + 项目名只在项目内）

对应改动：`lib/widgets/app_shell.dart`、`lib/theme/tokens.dart`、`lib/features/intake/intake_page.dart`

- 删掉右上角整组圆形头像（肖 / 王 / 何 / +1）连同「+1」；
- 顶栏右侧改为：**项目名 / 已自动保存 / 主题按钮 / 加号**，相邻间距统一 16px；
- 「项目名 + 已自动保存」只在五个流程路由（`/intake`、`/outline`、`/modules`、`/workspace`、`/delivery`）显示，
  判断依据是 `ModalRoute.settings.name`（`kProjectRoutes` 白名单 + `inProjectRoute()`），
  工作台 `/workbench`、首页态 `/`、未知路由一律隐藏；
- 两枚圆钮统一 36×36（新令牌 `T0.iconButtonSize`），原先主题 36 / 加号 34 不一致；
- 材料输入页导航高亮从「工作台」改为「当前项目」—— 它已经在项目第 1 步，右边既然显示项目名，高亮就得一致；
- 材料输入页「模拟解析失败」从无边框文本按钮改成和左右同形的胶囊描边按钮（`tone: danger`），不再像漏样式。

## 自检

**1. 顶栏右侧元素顺序与间距（1440 宽，widget 矩形，`test/topbar_test.dart` 断言）**

| 元素 | 左 | 右 | 宽 |
| --- | --- | --- | --- |
| 项目名「城市公共空间调研」 | 1121.8 | 1227.8 | 106.0 |
| 已自动保存 | 1243.8 | 1312.0 | 68.3 |
| 主题按钮 | 1328.0 | 1364.0 | 36.0 |
| 加号 | 1380.0 | 1416.0 | 36.0 |

- 相邻间距：`1227.8→1243.8 = 16.0`、`1312.0→1328.0 = 16.0`、`1364.0→1380.0 = 16.0`；
- 加号右边缘到视口右边 = **24px**（顶栏内边距），四个元素同一水平中线（中心 y 均为 35.5）；
- 像素扫描交叉验证：02/03 右侧正好 4 组像素 `1122-1226 / 1243-1311 / 1328-1363 / 1380-1415`，
  01/04 正好 2 组 `1328-1363 / 1380-1415`（组间 17 = 16px 空格 + 1px 端点像素）；
- 两枚圆钮在 1440 与 500 两种宽度下都由 `flutter test` 断言为 **36×36**。

**2. 四个状态顶栏高度**

`flutter test` 逐个路由断言 `topbar` 的矩形高度 = **72.0**（`/workbench`、`/intake`、`/outline`、`/modules`、`/workspace`、`/delivery`，含 `/` 首页态）；
像素侧再用 x=1000 一列往下找第一条非底色行交叉验证：01/02/03/04 全部 **72px（含 1px 下边框）**。

**3. 切主题时这一段是否跟着变**

黑夜截图（06）与 `test/topbar_test.dart` 的 `白天 ↔ 黑夜` 用例同时验证：

- 顶栏底色 `#FFFDF8 → #3A2F44`；
- 项目名字色跟着 `T0Palette.ink` 变（笔画平均亮度 0.188 → 0.610，浅底上是深字、深底上是亮字）；
- 切换前后项目名矩形完全相等（`expect(after, before)`）—— 只是换色，不换位置。

**4. 导航高亮与项目态一致（审图 P1）**

`test/topbar_test.dart` 的「导航高亮与项目态一致」6 条用例：`/workbench` 上「工作台」= `ink`、「当前项目」= `muted`；
五个流程路由上反过来。颜色取 `T0Palette`，不靠眼睛看。

## 复现

```bash
flutter analyze
flutter test
flutter build web --release
cd build/web && python -m http.server 8099 --bind 127.0.0.1
# 另开一个 shell，在仓库根目录：
python tool/shoot_topbar_screens.py
```

脚本自带硬断言：工作台两张必须只有 2 组右侧像素、项目内两张必须有 4 组，否则直接非零退出，不会产出「看起来对」的图。
